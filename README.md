# Лабораторная работа №5. Основы JavaScript и проектирования компонентов

**Цель:** научиться связывать HTML, CSS и JavaScript, обрабатывать события и обновлять элементы страницы.
**Вариант:** 1, 3, 5, 8, 9, 14, 20.

## Запуск

Распакуйте архив и откройте `index.html` в браузере. Установка пакетов, сборка и сервер не нужны. Каждый компонент — отдельная секция в `index.html` и отдельный скрипт. Сторонних библиотек и фреймворков нет.

| № | Компонент | Что проверить | Скрипт |
|---|---|---|---|
| 1 | Счётчик кликов | Несколько раз нажать «+1 Клик», затем сбросить | [counter.js](assets/js/counter.js) |
| 3 | Таймер | Задать 3 секунды, запустить, поставить на паузу и продолжить | [countdown.js](assets/js/countdown.js) |
| 5 | Аккордеон | Открыть и закрыть пункт, отсортировать список, поменять порядок стрелками | [accordion.js](assets/js/accordion.js) |
| 8 | Вкладки | Переключить панели мышью и клавишами ← / → | [tabs.js](assets/js/tabs.js) |
| 9 | Форма с проверкой | Отправить пустые поля, затем ввести Анна, anna@example.com и ИВТ-5 | [validation.js](assets/js/validation.js) |
| 14 | Генератор чисел | Задать границы −5 и 5, затем одинаковые границы 7 и 7 | [random.js](assets/js/random.js) |
| 20 | Анимация при наведении | Навести указатель и убрать его; на телефоне нажать кнопку эффекта | [hover.js](assets/js/hover.js) |

## Усложнения по варианту

- **Аккордеон:** сортировка по алфавиту в обе стороны и ручное перемещение пунктов вверх и вниз. Открытая панель сохраняется при перестановке.
- **Форма:** [отдельная страница](native-form.html) без подключённых скриптов. Проверка основана на атрибутах HTML, подсказки оформлены через CSS. Чтобы показать разницу, отключите JavaScript в браузере и повторите проверку на этой странице.

Слайдер и модальное окно не входят в выбранные семь компонентов.

## Загрузка на GitHub

1. Создайте пустой репозиторий, например `lab5-js-components`.
2. На странице репозитория выберите ссылку **uploading an existing file** в блоке **Quick setup**. Если в репозитории уже есть файлы, выберите **Add file → Upload files**.
3. Перетащите **содержимое распакованного архива**: `index.html`, `native-form.html`, `README.md`, папки `assets` и `docs`. Сохраните структуру папок.
4. Сохраните изменения. На главной странице репозитория должен отобразиться README, а `index.html` должен лежать в корне.

[Инструкция GitHub по загрузке файлов](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository)
