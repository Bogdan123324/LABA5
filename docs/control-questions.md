# Контрольные вопросы

## 1. Какие типы данных в JavaScript существуют?

Есть семь простых типов: `string` (строка), `number` (число), `bigint` (большое целое), `boolean` (истина или ложь), `undefined` (значение ещё не задано), `null` (явно заданное отсутствие значения), `symbol` (уникальный идентификатор). Остальные значения относятся к типу `object`. Массивы и функции тоже являются объектами.

## 2. Какой принцип работы JavaScript кода?

Движок читает и выполняет код. В браузере скрипт может найти элементы страницы и назначить им обработчики событий. Например, после клика обработчик меняет число на экране. В обычном скрипте синхронные команды выполняются по порядку; обработчик запускается позже, когда произошло событие и поток освободился.

## 3. Какие операторы в JavaScript существуют?

Арифметические: `+`, `-`, `*`, `/`, `%`, `**`. Присваивание: `=`, `+=`, `-=`. Сравнение: `===`, `!==`, `<`, `>`, `<=`, `>=`. Логические: `&&`, `||`, `!`. Есть и другие: побитовые, условный `условие ? да : нет`, проверка типа `typeof`, увеличение `++` и уменьшение `--`.

## 4. Перечислите и опишите циклы, которые существуют в JavaScript.

`for` — повторяет действия, обычно со счётчиком. `while` — проверяет условие перед каждым проходом. `do...while` — сначала выполняет тело, поэтому проходит хотя бы один раз. `for...of` перебирает значения, например элементы массива. `for...in` перебирает перечисляемые строковые ключи объекта. `forEach()` — метод массива для обхода элементов, а не отдельная конструкция цикла.

## 5. Что такое массив? Разновидности массивов. Каким способом можно объявить и проинициализировать массив в JavaScript?

Массив — упорядоченный список, у которого первый индекс равен 0. Бывают обычные одномерные и вложенные массивы, например таблица `[[1, 2], [3, 4]]`. В обычном массиве могут быть значения разных типов. Создать массив можно литералом `const a = [1, 2, 3]`, вызовом `Array.of(1, 2, 3)` или `Array.from("abc")`. Запись `new Array(3)` создаёт массив длины 3 с пустыми ячейками.

## 6. Что такое объекты в JavaScript? Как они хранятся и применяются. Приведите примеры.

Объект объединяет свойства с именами и значениями: `const student = { name: "Анна", group: "ИВТ-5" }`. Получить группу можно через `student.group`. Переменная хранит ссылку на объект; если присвоить её другой переменной, обе будут указывать на один объект. Объекты удобны для хранения связанных данных и методов.

## 7. Что такое DOM? Какие методы для работы с объектами DOM вы знаете?

DOM — представление страницы в виде дерева узлов. `getElementById()` ищет по идентификатору, `querySelector()` — первый элемент по CSS-селектору, `querySelectorAll()` — все совпадения. `createElement()` создаёт узел, `append()` добавляет его, `remove()` удаляет. Свойство `textContent` меняет текст, а `classList.add()` добавляет класс.

## 8. Что такое событие в JavaScript и как происходит обработка событий? Какие события JavaScript вы знаете?

Событие — сигнал о действии, например `click`, `input`, `submit`, `keydown` или `pointerenter`. Через `addEventListener()` назначаем функцию. Когда событие происходит, браузер вызывает её и передаёт объект события. У многих событий есть фаза захвата, целевой элемент и всплытие к родителям. Вызов `preventDefault()` отменяет стандартное действие, если событие допускает отмену.

## 9. Какие методы регулярных выражений в JavaScript вы знаете?

У `RegExp` есть `test()` (возвращает true или false) и `exec()` (даёт данные совпадения или null). У строк есть методы, которые принимают регулярное выражение: `match()` и `matchAll()` ищут совпадения, `search()` возвращает индекс первого совпадения, `replace()` заменяет часть строки, `split()` делит строку по шаблону.
