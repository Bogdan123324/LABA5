Аккордеон

Открывайте темы и меняйте их порядок.

Стрелки справа двигают пункты

  • Клик или ввод текста вызывает событие. JavaScript может выполнить функцию в ответ.

  • Массив хранит элементы по порядку. Номер первого элемента — ноль.

  • Объект хранит свойства с именами: например, имя и группу студента.

Вкладки

Три части обычной веб-страницы.

Структура

HTML задаёт элементы: заголовки, кнопки и поля ввода.

<button>Нажми меня</button>

Оформление

CSS определяет цвета, размеры и расположение элементов.

button { border-radius: 8px; }

Поведение

JavaScript реагирует на действие и обновляет страницу.

button.addEventListener('click', countClick);
