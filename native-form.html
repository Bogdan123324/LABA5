Форма без JavaScript

Браузер проверяет поля по правилам HTML. CSS подсвечивает ошибки и показывает подсказку у поля.

Все поля заполнены корректно. Учебные данные никуда не отправлены.

Данные студента

Введите имя из 2–50 символов. Используйте буквы; пробелы и дефисы допустимы между словами.

Введите адрес вида anna@example.com.

Введите 2–6 заглавных букв, дефис и 1–2 цифры. Например, ИВТ-5.
